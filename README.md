# 📖 About

TripFusion is a smart travel planning platform designed to simplify the entire journey planning experience. Users can explore destinations, create personalized travel plans, manage saved trips, receive trip notifications, and organize everything in one place through a clean and responsive interface.

The application combines secure authentication, itinerary management, destination discovery, email services, SMS notifications, PDF generation, and interactive travel utilities into a single platform.
